reading order. GitHub governance owns current scope, Decisions, Tickets and delivery
state; the relevant canonical contracts own business and technical meaning.

Run `pnpm agent:context` to identify the checkout and instruction revision before
assuming this directory is current. The command is read-only and reports missing
remote evidence as unknown.

context. Read them only when a current GitHub record cites them or the task explicitly
requires historical evidence. They are not the current strategic or delivery authority.
