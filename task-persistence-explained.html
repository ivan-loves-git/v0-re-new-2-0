The Key Insight

Without CLAUDE_CODE_TASK_LIST_ID, each session creates a random UUID directory. Your tasks exist but are orphaned. With it set to "renew-tasks", ALL sessions connect to the same 50 tasks.

❌ Before (Broken)

~/.claude/tasks/
├── a817899b-4ff0-... ← Session 1
├── 718cff6e-bb32-... ← Session 2
├── f210ee19-a7cd-... ← Session 3
└── renew-tasks/ ← Orphaned!
Each session creates new random directory.
50 tasks exist but nothing points to them.

✓ After (Fixed)

~/.claude/tasks/
└── renew-tasks/ ← ALL sessions
├── 1.json
├── 2.json
├── ...
└── 50.json
Every session connects to same directory.
Tasks persist across sessions forever.

The Fix

Added "env": { "CLAUDE_CODE_TASK_LIST_ID": "renew-tasks" } to .claude/settings.local.json. This tells Claude Code to use the named directory instead of generating random UUIDs.
