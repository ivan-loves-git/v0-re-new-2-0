# Roadmap workflow

`/guide/roadmap` preserves the existing editorial history of WAVE development. It is not the current delivery tracker, a release proof, or a second founder-reporting duty. Its older manual dates, versions, and counts are historical statements from the time they were written.

Current approved strategy and completed Product Change reporting come from the validated GitHub governance projection on `/strategic-pdr`; GitHub remains the delivery authority. Ticket #212 adds closure, release, approved summary, and freshness facts to that projection. No routine release requires a second manual roadmap entry, version bump, or red-dot update.

Ivan may explicitly request an editorial addition to the historical timeline. Codex owns that bounded edit and its factual review, using verified GitHub delivery evidence. The editorial trigger is Ivan's request, not a PR merge, code deployment, or an automatic job. An editorial entry never changes Product Change status, founder totals, or operational KPI actuals.
