# Re-New Certification Architecture

**14 Badges. 6 Readiness Dimensions. Verified Achievement.**

*Companion to: [PLATFORM_VISION_V2.md](./PLATFORM_VISION_V2.md)*

## Design Principles

Certifications are credible when they are **hard to get and easy to verify**. This architecture draws from proven models:

| Model | Lesson for Re-New |
|-------|-------------------|
| **CFA** (Chartered Financial Analyst) | Multi-year progression, rigorous standards, instant credibility |
| **PMP** (Project Management Professional) | Combination of education + experience + examination |
| **ICF** (International Coaching Federation) | Three-tier progression with experience-based advancement |
| **Upwork talent badges** | Percentage-based exclusivity creates aspirational hierarchy |
| **CRA** (37 years in France) | Structured training + mentoring + certification for repreneurs |

### Re-New's Certification Design Rules

1. **Verified, not self-declared**: Every certification requires evidence reviewed by Re-New or automated verification
2. **Achievement-based, not gamification**: Badges represent real milestones, not points accumulation
3. **Useful to third parties**: Each certification answers a specific question a seller or intermediary would ask
4. **Progressive and sequential**: Later certifications build on earlier ones
5. **Revenue-aligned**: Higher certifications require engagement that generates revenue (consulting, Pro subscription)

## The 6-Dimension Readiness Radar

Instead of a single score, Re-New displays a multi-dimensional readiness profile visible to repreneurs, the Re-New team, and eventually to sellers/intermediaries.

### Dimensions

| # | Dimension | What It Measures | Score Range | Data Sources |
|---|-----------|-----------------|-------------|--------------|
| 1 | **Financial Capacity** | Proof of funds, financing structure quality, post-close liquidity | 1-9 | WHEN score (financial questions), Financially Verified cert, Financing Secured cert |
| 2 | **Industry Expertise** | Years in target sectors, C-level experience, domain-specific knowledge | 1-9 | WHO score (professional experience), Tier 2 interview, Evaluation Competent cert |
| 3 | **Deal Experience** | Prior acquisitions, advisory background, formal training completed | 1-9 | WHO score (M&A exposure), Tier 2 interview, certifications earned (LDC, DD, Negotiation) |
| 4 | **Operational Capability** | Team management track record, crisis handling, change leadership | 1-9 | WHO score (leadership questions), Tier 2 interview (Leadership + Commitment dimensions) |
| 5 | **Network Strength** | Advisors retained, board members, industry connections, Re-New coaching | 1-9 | Team Ready cert, Tier 2 interview, advisory team composition |
| 6 | **Process Maturity** | Milestones completed, certifications earned, timeline adherence | 1-9 | Tier 3 milestones, certification count, journey stage progression |

### Scoring Logic

Each dimension uses a 1-9 scale inspired by the Technology Readiness Level (TRL) and Investment Readiness Level (IRL) frameworks:

| Score | Level | Meaning |
|-------|-------|---------|
| 1 | Awareness | Has heard of the concept, no practical knowledge |
| 2 | Exploration | Actively learning, reading, exploring |
| 3 | Foundation | Basic understanding, some preparation started |
| 4 | Development | Active preparation, building skills |
| 5 | Competent | Can handle basic scenarios independently |
| 6 | Proficient | Can handle most scenarios, knows when to get help |
| 7 | Advanced | Consistent track record, handles complexity well |
| 8 | Expert | Deep expertise, can mentor others |
| 9 | Mastery | Proven track record through completed journey |

### How Dimensions Map to Existing Data

```
Re-New's 3-Tier Assessment -> Readiness Radar

Tier 1 (WHO score, automated):
  Professional experience questions -> Industry Expertise (dim 2)
  Leadership/management questions  -> Operational Capability (dim 4)
  M&A exposure questions          -> Deal Experience (dim 3)

Tier 1 (WHEN score, automated):
  Financial capacity questions    -> Financial Capacity (dim 1)
  Project maturity questions      -> Process Maturity (dim 6)
  Financial coherence flags       -> Financial Capacity (dim 1, negative)

Tier 2 (Interview, human):
  Leadership dimension            -> Operational Capability (dim 4)
  Financial Acumen dimension      -> Financial Capacity (dim 1)
  Communication dimension         -> Deal Experience (dim 3)
  Clarity of Vision dimension     -> Process Maturity (dim 6)
  Coachability dimension          -> Network Strength (dim 5)
  Commitment dimension            -> Operational Capability (dim 4)

Tier 3 (Milestones):
  Each completed milestone        -> Process Maturity (dim 6)
  Specific milestones validate    -> Corresponding dimension
    LDC validated                 -> Deal Experience (dim 3)
    Financing secured             -> Financial Capacity (dim 1)
    Advisory team confirmed       -> Network Strength (dim 5)
```

## Certification Progression Rules

### Prerequisites

Not all certifications are available immediately. Prerequisites ensure credibility:

| Certification | Prerequisites |
|--------------|---------------|
| Explorer | None (entry point) |
| Profile Verified | Explorer |
| Thesis Validated | Profile Verified |
| Financially Verified | Profile Verified |
| Team Ready | Profile Verified |
| Active Searcher | Thesis Validated + Financially Verified |
| Evaluation Competent | Active Searcher |
| LDC Validated | Evaluation Competent |
| DD Competent | LDC Validated |
| Negotiation Ready | DD Competent |
| Financing Secured | Negotiation Ready |
| Deal Closed | Financing Secured |
| Transition Complete | Deal Closed |
| Certified Repreneur | Transition Complete |

### Parallel Tracks

Some certifications can be earned in parallel:
- Thesis Validated, Financially Verified, and Team Ready can all be worked on simultaneously after Profile Verified
- Active Searcher requires both Thesis Validated AND Financially Verified (need to know what you want AND that you can pay for it)

### Expiration and Renewal

| Certification | Expiration | Renewal |
|--------------|------------|---------|
| Explorer | Never expires | N/A |
| Profile Verified | 2 years | Re-interview |
| Thesis Validated | 1 year | Update and re-review |
| Financially Verified | 6 months | Re-upload current proof |
| Team Ready | 1 year | Confirm team still active |
| Active Searcher | 3 months inactive | Resume activity |
| All deal-specific certs | Never expire | N/A (achievement-based) |

## Shareable Profiles (Future)

When Re-New wants to present a repreneur to a seller or intermediary, the platform generates a profile that includes:

1. **Readiness radar** (6-dimension chart)
2. **Certification badges** earned (with verification dates)
3. **Journey phase** (X/13 completed)
4. **Target criteria** (sector, geography, deal size)
5. **Financial capacity summary** (verified range, not exact figures)
6. **Professional background** (anonymized until introduction approved)

This profile becomes a **trust document** that intermediaries and sellers can rely on, similar to how a bank pre-approval letter works in real estate.

### Privacy Controls

Repreneurs control what's visible:
- **Always visible**: Certification badges, readiness radar scores, journey phase
- **Optional**: Professional background, target criteria details
- **Never shared**: Financial amounts, personal contact info (until intro approved)
