Founder brief · July 2026

Wave 2.0 now feels like one professional operating system.

We redesigned the complete working interface around one mature, Primer-inspired Re-New system: calmer navigation, clearer decisions, denser work surfaces, consistent records, and reusable rules for every future screen.

Released as Wave build 508 · staff workspace and repreneur portal

Executive summary

Why this matters now

The redesign turns Wave from a collection of useful features into a governed product. Shadcn remains the component engine underneath, while the new WAVE layer decides how Re-New uses density, hierarchy, filtering, charts, status, navigation, and records. This gives founders a more credible product today and a safer base for faster AI-assisted development tomorrow.

01 · One operating language

Every screen now belongs to Wave

The sidebar, headers, dashboards, tables, cards, records, forms, portal and public flows now share one hierarchy, spacing model, palette and interaction language.

02 · Faster operational reading

Decisions appear before decoration

Dashboards prioritize queues and next actions. Records lead with identity and the next best action. Tables carry more useful information with less visual noise.

03 · Governed future growth

AI work now has real guardrails

Shared WAVE components, URL-backed filters and an EvilCharts facade make future additions faster without allowing each generated screen to invent a new design.

What changes for founders and staff

  • Every major staff surface was rationalized: dashboards, analytics, directories, pipeline, opportunities, offers, emails, Wavy, settings, guide and record journeys.
  • The public intake, assessment, authentication and repreneur portal now inherit the same visual foundation.
  • All charts route through one Re-New-owned EvilCharts layer with a consistent palette and accessible data tables.
  • Keyboard behavior, mobile navigation, responsive tables, reduced motion, sorting and pagination were audited and refined.
  • The live Design System and written WAVE contract make the approved rules visible and reusable inside the product.

What remains intentionally flexible

The system is strict about hierarchy, spacing, filters and charts, but flexible about new workflows. We can now improve individual journeys from real operating use without reopening the visual foundation each time.
