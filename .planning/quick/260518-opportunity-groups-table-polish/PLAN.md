# Opportunity Groups Table Polish

## Goal

Bring the Opportunities Groups page closer to the Repreneurs Groups visual pattern: less clutter, clearer columns, and more consistent colored tags.

## Scope

- Split grouped opportunity tag data into separate `Journey`, `Status`, `Visibility`, and `Pursuit` columns.
- Reduce secondary row detail in the grouped table by removing activity, location, size, and added-date columns from this denser view.
- Give opportunity journey, status, visibility, and pursuit signals explicit color treatments.

## Result

Implemented in the shared opportunity work-surface table and opportunity badge components. Richer fields remain available in Find and on the opportunity detail page.
