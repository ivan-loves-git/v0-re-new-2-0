# 04-01: WHO/WHEN Inline Score Editors

## Objective
Add pencil icon editors to the WHO and WHEN score sections on the repreneur profile page. Each opens a popup dialog where admins can edit answers and recalculate scores.

## Success Criteria
1. Admin clicks WHO pencil → popup with Q05-Q10 editable
2. Admin clicks WHEN pencil → popup with Q11, Q14-Q16 editable
3. "Calculate & Save" updates answers AND recalculates scores atomically
4. Score breakdown on profile reflects new values immediately

## Tasks

### Task 1: Create WhoScoreEditor Component
**File:** `components/repreneurs/who-score-editor.tsx`

Features:
- Dialog trigger (pencil icon)
- RadioGroup for each WHO question (Q05-Q10)
- Live score preview using `calculateWhoScore()`
- Cancel and "Calculate & Save" buttons
- Uses existing `saveQuestionnaireV2()` server action
- Toast feedback on save

Props:
```typescript
interface WhoScoreEditorProps {
  repreneur: Repreneur
  onSaved?: () => void
}
```

### Task 2: Create WhenScoreEditor Component
**File:** `components/repreneurs/when-score-editor.tsx`

Features:
- Dialog trigger (pencil icon)
- CheckboxGroup for Q11 (project status - multi-select)
- CheckboxGroup for Q14 (deal size - multi-select)
- CheckboxGroup for Q15 (structure - multi-select)
- RadioGroup for Q16 (equity - single-select)
- Live score preview using `calculateWhenScore()`
- Flags display using `detectFlags()`
- Cancel and "Calculate & Save" buttons

Note: Q12 (geo zones) and Q13 (sectors) are informational only - not included in editor.

### Task 3: Add Pencil Icons to Profile Rating Card
**File:** `app/(dashboard)/repreneurs/[id]/page.tsx`

Modifications:
- Import WhoScoreEditor and WhenScoreEditor
- Add pencil icon next to WHO score display (lines ~380)
- Add pencil icon next to WHEN score display (lines ~400)
- Wrap score sections with editor trigger

### Task 4: Test and Verify
- Open a repreneur profile with existing scores
- Click WHO pencil → verify current values pre-populated
- Change an answer → verify live score preview updates
- Save → verify score persists and page refreshes
- Repeat for WHEN editor
- Verify flags display correctly when triggered
