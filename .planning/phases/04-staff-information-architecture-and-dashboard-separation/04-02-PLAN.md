# Plan 04-02: Separate Repreneur and Opportunity Dashboards

## Tasks

- Move the current repreneur dashboard content to `/dashboard_re`.
- Remove opportunity KPI and freshness panels from the repreneur dashboard.
- Move current repreneur analytics content to `/analytics_re`.
- Add `/dashboard_op` as the operational opportunity dashboard with freshness, pending responses, active pursuits, NDA blockers, and recent opportunity records.
- Add `/analytics_op` as the dedicated opportunity KPI page using the existing opportunity KPI panel.

## Acceptance

- Page titles include the group name in the main heading.
- Opportunity operational work appears on `/dashboard_op`.
- Opportunity metrics appear on `/analytics_op`.
- Repreneur dashboard and analytics no longer blend opportunity content.
