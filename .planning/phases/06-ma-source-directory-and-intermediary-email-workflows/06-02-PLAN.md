# Plan 06-02: M&A Source Directory UI

## Goal

Staff can manage M&A intermediaries from a dedicated Opportunity page.

## Tasks

1. Add server actions to list, create, and update M&A sources with opportunity stats.
2. Add `/opportunities/ma` with `SectionPageHeader`, stats, source table, and add/edit dialogs.
3. Add `M&A` to the Opportunities sidebar group.
4. Update breadcrumb/floating nav labels.

## Acceptance

- Staff can create a source.
- Staff can edit source contact name, email, phone, type, and notes.
- The page shows opportunity counts and stale/open signals.
- No source details are added to repreneur-facing routes.
