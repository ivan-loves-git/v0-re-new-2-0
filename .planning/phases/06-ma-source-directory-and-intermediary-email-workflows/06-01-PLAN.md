# Plan 06-01: Data Foundation and Source Backfill

## Goal

Make `ma_sources` usable as a directory by linking existing opportunity `source_label` values to normalized source records.

## Tasks

1. Add a SQL script that:
   - ensures editable email template columns exist;
   - inserts missing M&A email template rows;
   - inserts missing `ma_sources` from distinct opportunity source labels;
   - updates opportunities to point to matching `ma_sources`;
   - adds useful comments/indexes/grants without widening source exposure.
2. Apply the script to the approved Supabase project.
3. Verify row counts before/after.

## Acceptance

- Existing demo opportunities have `source_id` populated where `source_label` exists.
- M&A email template rows exist.
- Script is idempotent and safe to rerun.
