# Plan 06-03: Intermediary Email Templates

## Goal

Email Tools can review M&A/intermediary templates without mixing them into repreneur manual sending.

## Tasks

1. Add M&A template keys and metadata with `Opp` audience tags.
2. Add a generic editable email renderer for M&A templates.
3. Seed useful editable template copy in the database.
4. Keep manual repreneur sending focused on repreneur templates; allow M&A templates in review/test preview.

## Acceptance

- Templates page shows the new M&A templates with `Opp` tags.
- Preview dialog renders each M&A template.
- Test sending can render the templates.
- Repreneur manual send does not accidentally offer M&A templates as if they were repreneur emails.
