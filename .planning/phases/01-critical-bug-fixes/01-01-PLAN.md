    Add experimental.serverActions.bodySizeLimit configuration to allow file uploads up to 10MB.

    Current next.config.mjs structure:
    ```javascript
    const nextConfig = {
      typescript: {...},
      images: {...},
      env: {...},
      async redirects() {...},
    ```

    Add after the existing config options:
    ```javascript
    const nextConfig = {
      typescript: {...},
      images: {...},
      env: {...},
      experimental: {
        serverActions: {
          bodySizeLimit: '10mb',
        },
      },
      async redirects() {...},
    }
    ```

    Note: This is for Next.js 14+. The default is 1MB which causes files to fail silently.
