# 02-02 Plan: Repreneur Opportunity Access and Anonymized Detail

## Goal

A logged-in repreneur can see only the opportunities that staff explicitly proposed to them, using anonymized opportunity data only.

## Decisions

- Use login email matching for June: `user.email` maps to `repreneurs.email`.
- Show matches only when `opportunity_matches.status` is `proposed`, `interested`, or `active_pursuit`.
- Show opportunities only when the opportunity is active and `repreneur_visibility` is not `staff_only`.
- Do not expose source/contact, raw staff description, staff notes, documents, or profile editing.

## Acceptance Criteria

- A login with no matching repreneur profile sees no opportunity data.
- A matching repreneur sees only proposed or already-active matches.
- Staff-only opportunities and draft/shortlisted matches stay hidden.
- Repreneur-facing views never select or render source/contact/staff-only fields.
