# 02-04: Interest / Reject Actions and Staff Review Flow

## Goal

Repreneurs can respond to proposed opportunities from the external portal, and Re-New staff can see which responses need review.

## Scope

- Add portal actions on an opportunity detail page:
  - `I'm interested`
  - `Not a fit`
- Store the response using the existing `opportunity_matches.status` values:
  - `interested`
  - `declined`
- Reset `reviewed_by` / `reviewed_at` when a repreneur responds so staff can identify new responses.
- Add a staff review queue at `/opportunities/reviews`.
- Let staff mark a response as reviewed without converting it into an active pursuit.

## Out Of Scope

- Converting interest into active pursuit.
- Locking an opportunity to one active repreneur.
- NDA or document download gating.
- Email or Slack notifications.
- Free-text repreneur comments.

## Tasks

1. Add server actions for repreneur interest/decline.
2. Add server actions and data loaders for staff response review.
3. Add portal response UI to opportunity detail.
4. Add staff review queue page and sidebar entry.
5. Verify with the demo repreneur account and staff routes.

## Success Criteria

- A proposed match can be marked interested from the portal.
- A proposed/interested match can be marked declined from the portal.
- Staff can see interested/declined responses in a dedicated review queue.
- Staff can mark a response reviewed while keeping the response status unchanged.
- Active pursuit is not created in this plan.

## Executive Summary

This plan adds the first true two-way interaction in the separated repreneur portal. A repreneur can now tell Re-New whether a proposed deal is interesting or not.

For staff, the key point is control: responses become a review queue, not automatic deal progression. The team still decides what to do next in the later active-pursuit step.
