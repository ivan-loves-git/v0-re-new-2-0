# 02-05: Validated Pursuit, Active Lock, and Reopen Logic

## Goal

Re-New staff can convert one repreneur's interest into the single active pursuit for an opportunity, while keeping the opportunity reopenable if that pursuit is dropped.

## Scope

- Add a database-level lock that allows only one `active_pursuit` match per opportunity.
- Add staff actions to:
  - validate an interested match into `active_pursuit`
  - drop an active pursuit into `dropped`
  - reopen a dropped pursuit back into staff review
- Show active-pursuit lock state on the opportunity recommendations tab.
- Add validate/drop/reopen controls to staff review and recommendation surfaces.
- Keep repreneur portal access read-only once a pursuit is active.

## Out Of Scope

- Deal stage timeline after active pursuit.
- NDA signing or document gating.
- Email notifications.
- Full CRM activity history.
- Automatic matching or automatic validation.

## Tasks

1. Add additive SQL for the active-pursuit uniqueness guard.
2. Add staff server actions for validate, drop, and reopen.
3. Update review queue data so staff can see active lock conflicts.
4. Update opportunity recommendation UI with active lock controls.
5. Verify same-project migration, staff workflow, repreneur portal state, and lock behavior.

## Success Criteria

- Staff can validate an `interested` match into `active_pursuit`.
- A second `active_pursuit` for the same opportunity is blocked by the database, not only by UI.
- Staff can drop the active pursuit and then validate another interested match.
- Dropped matches can be reopened into the review queue.
- Repreneurs cannot change their response after staff validates the pursuit.

## Executive Summary

This plan adds the control point Bertrand and the Re-New team need before a deal becomes operational. Repreneur interest is still only a signal; staff must explicitly validate one pursuit.

The lock is deliberately strict but reversible. Only one repreneur can be active on an opportunity at a time, and dropping that pursuit reopens the opportunity for another validated path.
