# Plan 05-02: Unify Repreneur Groups and Find Visual Structure

**Status:** planned
**Phase:** 5 - Unified Find and Groups Work Surfaces

## Goal

Make repreneur Groups and Find feel like two views of the same operating system: same visual rhythm, filter quality, pagination behavior, colors, tags, and row density.

## Scope

- Keep `/repreneurs` as Groups.
- Keep `/repreneurs/explore` as Find.
- Improve visual consistency between `RepreneurTable` and `RepreneurExploreTable`.
- Preserve current data behavior and row navigation.
- Avoid changing repreneur scoring or journey derivation logic.

## Tasks

1. Align page headers, action buttons, export button placement, and helper copy.
2. Align filter bar layout, spacing, select widths, search behavior, and reset behavior.
3. Align badge styles for lifecycle status, journey, assessment, offers, and recommendations.
4. Align table density, row hover, avatar/name cell, date cell, score cell, and empty states.
5. Make pagination behavior predictable in both grouped and flat modes.
6. Check mobile behavior so filters wrap cleanly and table text does not overlap.

## Acceptance Criteria

- Groups and Find look intentionally related at a glance.
- Both pages keep their distinct purpose: grouped operating buckets versus flat search.
- Existing repreneur filters and row navigation still work.
- Paginated grouped tables show clear counts and do not resize awkwardly.
- No unrelated dashboard or profile behavior changes.

## Verification

- Run `npm run lint`.
- Run `npm run build`.
- Browser test `/repreneurs` and `/repreneurs/explore` on desktop and mobile widths.
- Test search, at least two filters, pagination, row navigation, and export access.

## Executive Summary

This plan cleans up the two main repreneur work pages so the team does not feel like they are switching between two different products. Groups remains for pipeline buckets, and Find remains for precise searching.

The output should be calmer, more consistent, and easier to scan, with the same controls appearing in the same place and the same tag language across both pages.
