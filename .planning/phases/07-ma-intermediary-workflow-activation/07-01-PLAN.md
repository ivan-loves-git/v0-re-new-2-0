# 07-01 Plan: Data and Server Workflow

## Objective

Create the staff-only data and server action layer for opportunity-specific M&A intermediary email workflows.

## Tasks

1. Add additive SQL migration for `ma_source_interactions`.
2. Add TypeScript interaction types.
3. Add server action to list opportunity M&A interactions.
4. Add server action to send an M&A intermediary email:
   - validate staff access
   - load opportunity with source
   - validate source contact email
   - validate template is an M&A template
   - substitute opportunity/source/repreneur variables
   - send via existing email infrastructure
   - log interaction
   - revalidate opportunity detail and M&A directory

## Acceptance Criteria

- No existing table is destructively changed.
- Missing source email returns a friendly error.
- M&A workflow logs are opportunity/source scoped.
