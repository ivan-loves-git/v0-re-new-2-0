# 07-02 Summary: Opportunity M&A Workflow UI

## Result

Added an M&A tab to opportunity detail pages.

The tab lets staff:

- See linked source/contact status.
- Select an intermediary email template.
- Review and edit the generated subject and message.
- Send the email from the opportunity context.
- See previous intermediary interactions.
