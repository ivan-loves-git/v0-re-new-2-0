# 07-02 Plan: Opportunity M&A Workflow UI

## Objective

Add a staff-facing M&A workflow surface to opportunity detail.

## Tasks

1. Add an `M&A` tab to opportunity detail.
2. Create `OpportunityMaWorkflowPanel`.
3. Show source/contact context.
4. Show template selector, editable subject, editable body, and send button.
5. Show recent M&A interaction history.
6. Use existing toast success/error feedback.

## Acceptance Criteria

- Staff can act without leaving the opportunity.
- Send action is blocked clearly when no source email exists.
- The interface remains visually consistent with existing opportunity tabs.
