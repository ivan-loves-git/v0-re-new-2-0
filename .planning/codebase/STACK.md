## Configuration

**Environment Variables (from `.env.example`):**

Required:
- `NEXT_PUBLIC_SUPABASE_URL` - Supabase project URL
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` - Supabase anonymous key (public, safe for browser)
- `SUPABASE_SERVICE_ROLE_KEY` - Supabase service role (server-only, bypass RLS)
- `DATABASE_URL` - PostgreSQL connection string (from Supabase)
- `BETTER_AUTH_SECRET` - 32+ character secret for auth encryption
- `BETTER_AUTH_URL` - Application base URL
- `RESEND_API_KEY` - Email service API key
- `RESEND_FROM_EMAIL` - Verified sender email
- `RESEND_WEBHOOK_SECRET` - Webhook signature verification
- `CRON_SECRET` - Vercel cron job authentication token

Optional (for AI features):
- `OPENAI_API_KEY` - OpenAI models
- `ANTHROPIC_API_KEY` - Claude models
- `PERPLEXITY_API_KEY` - Perplexity API
- `GOOGLE_API_KEY` - Google Gemini
- `MISTRAL_API_KEY` - Mistral AI
- `XAI_API_KEY` - xAI models
- `GROQ_API_KEY` - Groq models
- `OPENROUTER_API_KEY` - OpenRouter aggregator
- `AZURE_OPENAI_API_KEY` - Azure OpenAI
- `OLLAMA_API_KEY` - Local Ollama server
- `GITHUB_API_KEY` - GitHub import/export

**Validation:**
- Environment validation happens at build time via `lib/env.ts` using Zod
- Missing required vars cause build failure

**Build Configuration:**
- `next.config.mjs` - Configures image optimization, git build metadata, redirects
- `tsconfig.json` - Strict TypeScript with @ path alias
- `vitest.config.ts` - Test environment (node), coverage with V8
